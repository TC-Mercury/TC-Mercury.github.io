Mercury Logic

Tired of massive, messy vanilla Redstone contraptions? Welcome to a highly optimized, low-level system design mod bringing real-world digital electronics directly into Minecraft.

CurseForge Modrinth

Core Features (v1.0.0 Foundation)

Comprehensive Logic Gates

Seamlessly compute signals with compact and fully insulated AND, OR, NOT, NAND, NOR, XOR, and XNOR gates.

Advanced Memory Units

Store and toggle complex states reliably using edge-triggered Latches and Flip-Flops designed for engineers.

Clean Routing Systems

Eliminate cross-talk and messy wiring with insulated cables, T-Junctions, Elbows, and Bridge components.

Smart Transmission

Shoot signals straight up or down with Vertical Repeaters, or automatically lock and route incoming signals using Bidirectional Repeaters.

Developer's Note: A Solo Journey

Mercury Logic is a solo-developed passion project built for engineers, automation enthusiasts, and Redstone tinkerers. Version 1.0.0 serves as the solid "Core Foundation" of the mod. The architecture is built, the logic is sound, but this is only the beginning. The roadmap includes much larger computing systems and more complex automated functions.

  • Platform: Minecraft Forge / Fabric (Java)
  • Design Philosophy: Low-level system integration mirroring real-world digital electronics and logic design.
  • Community Driven: Active development phase relying on community feedback for hitbox adjustments, feature requests, and bug reports.
  • Current Status: v1.0.0 (Core Foundation) Released. Made with determination!
