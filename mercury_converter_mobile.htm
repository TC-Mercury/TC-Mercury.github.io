Core Features & Engineering

Native Share Integration

Deep integration with Android's Share Sheet (ACTION_SEND). Custom Regex strips away unnecessary text from shared payloads to ensure a 100% clean URL.

Anti-Bot Bypass

Utilizes yt-dlp nightly builds and client emulation (android_testsuite) to successfully bypass modern PO Token and HTTP 403 restrictions.

On-Device FFmpeg

Implements manual detective logic to locate the libffmpeg.so binary across various system directories, preventing architecture-specific crashes.

SQLite Download History

Securely logs past downloads in a local SQLite database, accessible via a sleek Bottom Sheet UI with Smart Auto-Paste functionality.

Technical Specifications

  • Language & Platform: Java, Native Android SDK
  • Core Engines: yt-dlp (Nightly), FFmpeg-Android
  • Storage Handling: Scoped Storage compliant (Android 11+), automatically organizes files by writing them directly to the Downloads/MercuryFile directory.
  • UI / UX: Dynamic Dark/Light Mode support with custom "Mercury" color palette.
  • Optimization (APK Size): Excluded x86 (Emulator) architecture via ABI Filtering to reduce production APK size from ~300MB to ~150MB.
