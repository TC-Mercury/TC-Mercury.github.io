The next-generation media conversion tool. Rebuilt from the ground up for maximum performance, seamless system integration, and advanced audio tagging.

View Source on GitHub

Engineering & Features

Architectural Evolution

Transitioned from the legacy Java Swing UI (V1) to a robust C++ and Qt Framework architecture (V2) for superior memory management and native OS performance.

Advanced Metadata Injection

Automatically fetches and embeds ID3 metadata and high-resolution cover art directly into the MP3 files during the conversion process.

Live Progress Tracking

Features a custom-built, responsive progress bar that visualizes active downloads and conversion status in real-time without blocking the main UI thread.

Mercury Standards & Localization

Built with strict adherence to the "Mercury Standards" for error handling. Includes auto-adapting multi-language support based on system preferences.

Technical Specifications

  • Core Architecture: C++ paired with Qt Framework (V2).
    (Note: V1 was originally prototyped in Java Swing).
  • Media Engines: yt-dlp integration combined with FFmpeg for audio extraction and post-processing.
  • File Management: Automatically organizes downloaded files into a dedicated MercuryFile directory for a clutter-free user experience.
  • Data Handling: Maintains a structured download history, allowing users to track previously converted media.
